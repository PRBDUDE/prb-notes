Use putty to copy the npi502 file to the raspberry pi

To transfer your newly generated npi502_ed25519 keys to your Raspberry Pi using the PuTTY suite, you will want to use PSCP (PuTTY Secure Copy Client). This is a command-line tool that comes bundled with PuTTY.

Here is how to get your public key onto your Raspberry Pi (pi5) so you can log in securely.

Step 1: Locate the Public Key

Make sure you are copying the public key (.pub), not your private key.

If you generated your key on Windows, it is likely sitting in your .ssh directory:

Plaintext C:\Users\YourUsername\.ssh\npi502_ed25519.pub

Step 2: Use PSCP to Transfer the Key

Open PowerShell or Command Prompt on your Windows machine and run the following command to copy the public key file over to the pi5 user's home directory on the Raspberry Pi:

PowerShell pscp ~\.ssh\npi502_ed25519.pub pi5@YOUR_PI_IP_ADDRESS:/home/pi5/

(Replace YOUR_PI_IP_ADDRESS with your actual local IP address, like 192.168.1.50).

Note: PSCP will prompt you for the password of your pi5 account to authorize the transfer.

Step 3: Authorize the Key on the Raspberry Pi

Now that the file is physically on the Pi, you need to append it to the authorized_keys file so the SSH server knows to trust it.

  1. Open PuTTY and log into your Raspberry Pi as pi5 using your password.
  2. Run the following commands to set up the SSH directory and append the key:
Bash
# Ensure the .ssh directory exists with the correct permissions
mkdir -p ~/.ssh
chmod 700 ~/.ssh

# Append the transferred public key to the authorized_keys file
cat ~/npi502_ed25519.pub >> ~/.ssh/authorized_keys
chmod 600 ~/.ssh/authorized_keys

# Clean up the loose file from your home folder
rm ~/npi502_ed25519.pub

Step 4: Configure PuTTY to Use Your Private Key

To use this key for future passwordless logins via the PuTTY graphical interface, you need to point PuTTY to your private key.

Because PuTTY uses its own key format ( .ppk), you need to do a quick conversion first:

A. Convert the Key with PuTTYgen

  1. Launch PuTTYgen (PuTTY Key Generator).
  2. Click File → Load private key.
  3. Change the file type filter in the bottom right from "PuTTY Private Key Files (.ppk)" to "All Files (.*)".
  4. Navigate to C:\Users\YourUsername\.ssh\ and select your private key: npi502_ed25519.
  5. Once loaded, click Save private key and save it in the same directory as npi502.ppk.

B. Add the Key to Your PuTTY Session

  1. Open PuTTY.
  2. In the left sidebar, navigate to Connection → SSH → Auth → Credentials.
  3. Look for the field labeled Private key file for authentication and click
    Browse....
  4. Select your newly saved npi502.ppk file.
  5. Go back to the Session category at the very top of the left sidebar.
  6. Enter your Pi's IP address under Host Name.
  7. Type a name in the Saved Sessions box (e.g., Raspberry Pi 5) and click
    Save.

Now, you can just double-click your saved session to log in instantly using your custom SSH key!
