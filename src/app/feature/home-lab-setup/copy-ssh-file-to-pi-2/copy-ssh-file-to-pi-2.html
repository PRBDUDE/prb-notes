Use putty on a Windows 11 machine to copy the npi502_ed25519 file to the raspberry pi

To transfer a file from Windows 11 to a Raspberry Pi using the PuTTY suite, you will use pscp (PuTTY Secure Copy Client), which comes installed automatically alongside PuTTY.

Method 1: Using pscp (Command Line)

  1. Open Command Prompt or PowerShell on Windows 11:
    • Press Win + R, type cmd or powershell, and press Enter.
  2. Navigate to the Directory containing your file (or specify the full path):
    3. DOS cd C:\path\to\your\file
  3. Run the pscp Command:
    4. DOS pscp npi502_ed25519 username@raspberrypi.local:/home/username/
    • Replace username with your Raspberry Pi account username (e.g., pi).
    • Replace raspberrypi.local with your Raspberry Pi's hostname or IP address (e.g., 192.168.1.100).
    • /home/username/ is the destination directory on the Raspberry Pi.
  4. Authenticate:
    • If prompted, accept the host key (type y).
    • Enter your Raspberry Pi user password when prompted.

Method 2: Using PSFTP (Interactive SFTP Tool)

If you prefer an interactive interface supplied with PuTTY:

  1. Search for PSFTP in your Windows Start Menu and open it.
  2. Connect to your Raspberry Pi: Plaintext open username@192.168.1.100
  3. Enter your password when prompted.
  4. Upload the file using the put command: Plaintext put "C:\path\to\npi502_ed25519"
  5. Type quit to exit once complete.
Tip: If you prefer a full drag-and-drop graphical interface, WinSCP integrates natively with PuTTY sessions and saved keys.
