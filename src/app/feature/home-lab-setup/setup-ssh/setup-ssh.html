Setup ssh from windows to raspberry pi - assign pi502 as the file name

To set up key-based SSH authentication from your Windows machine to your Raspberry Pi using your preferred key name (npi502_ed25519), follow these step-by-step instructions.

This guide covers generating the key pairs using standard Windows tools (like OpenSSH or PuTTY) and configuring the connection.

Option 1: Using Windows Built-in OpenSSH (Recommended)

If you are using the Windows Command Prompt or PowerShell, you can use the built-in OpenSSH tools.

1. Generate the Key Pair

Open PowerShell on your Windows machine and run the following command to create a secure Ed25519 key pair:

PowerShell
cd ~\.ssh
ssh-keygen -t ed25519 -f pi502_ed25519
  • Passphrase: You can enter a passphrase for extra security, or press Enter twice to leave it blank.
What this does: This creates two files in your C:\Users\YourUsername\.ssh\ folder:
  • npi502_ed25519: Your private key (keep this extremely secure and never share it).
  • npi502_ed25519.pub: Your public key (the "lock" you will put on your Raspberry Pi).

2. Copy the Public Key to the Raspberry Pi

You need to append the contents of npi502_ed25519.pub to the ~/.ssh/authorized_keys file on your Pi.

The easiest way to do this from Windows PowerShell is:

PowerShell
cd ~\.ssh
type npi502_ed25519.pub | ssh pi5@<your_pi_ip> "mkdir -p ~/.ssh && chmod 700 ~/.ssh && cat >> ~/.ssh/authorized_keys && chmod 600 ~/.ssh/authorized_keys"

(Replace pi5 with your Pi's username and <your_pi_ip> with your local network IP).

3. Connect Using the Key

To connect using your custom-named key, use the -i flag to specify the identity file:

DOS ssh -i C:\Users\YourName\.ssh\npi502_ed25519 pi5@<your_pi_ip>

Option 2: Using PuTTY

If you prefer using a graphical interface like PuTTY, follow these steps:

1. Generate the Key with PuTTYgen

  1. Launch PuTTYgen.
  2. Under Parameters (at the bottom), select Ed25519.
  3. Click Generate and move your mouse around the blank area to create randomness.
  4. Once generated, click Save private key. Name it npi502_ed25519.ppk.
  5. Click Save public key and name it npi502_ed25519.pub.
  6. Keep the PuTTYgen window open; copy the entire text string from the box labeled "Public key for pasting into OpenSSH authorized_keys file".

2. Add the Public Key to the Pi

Log into your Raspberry Pi via PuTTY using your password.

Open or create the authorized keys file:

Bash mkdir -p ~/.ssh && chmod 700 ~/.ssh nano ~/.ssh/authorized_keys

Paste the text string you copied from PuTTYgen into this file.

Press Ctrl + O then Enter to save, and Ctrl + X to exit.

Set correct permissions:

Bash chmod 600 ~/.ssh/authorized_keys

3. Configure PuTTY to Use the Key

  1. Open PuTTY.
  2. Go to the Session category and enter your Pi's IP address.
  3. In the left sidebar, navigate to Connection -> SSH -> Auth -> Credentials.
  4. In the Private key file for authentication field, click Browse... and select your npi502_ed25519.ppk file.
  5. Go back to Session, type a name under Saved Sessions (e.g., "Raspberry Pi 5"), and click Save.
  6. Click Open to connect passwordlessly.
