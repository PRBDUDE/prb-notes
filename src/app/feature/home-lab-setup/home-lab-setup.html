Purpose

A Home Lab is an environment used for learning. It isolates your development from the world and keeps your work private within your local network..

In this section I have included my notes on how to setup a Home Lab.

Environment

I am using a Raspberry PI 5 as my local webapp server. I develop my sites on a Windows or on a Mac machine.

My goal is to setup a local DNS server on my Raspberry PI and have my local router use that DNS server to be able to access my local websites.

I plan on using NGINX as my server environment.
