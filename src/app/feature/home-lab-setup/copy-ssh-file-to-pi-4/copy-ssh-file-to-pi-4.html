Method 1: Using pscp (PuTTY Command Line Tool)

If you installed PuTTY via the standard installer, pscp.exe is usually available in your system path.

1. Open PowerShell or Command Prompt

Press Win + X and select PowerShell or Terminal.

2. Run the pscp Command

Navigate to the directory where your file is located, or provide the full path to npi502_ed25519:

PowerShell pscp C:\path\to\npi502_ed25519 pi_username@raspberrypi_ip:/home/pi_username/

  • Replace pi_username with your username on the Raspberry Pi (e.g., pi or your custom user).
