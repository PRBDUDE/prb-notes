angular 22 - example of IdleService

In Angular 22, the ecosystem has firmly embraced a Signal-First and Zoneless-by-default architecture.

Building an IdleService without relying on legacy Zone.js execution paradigms requires leveraging Angular's fine-grained reactivity using native Signals, effect(), and lean RxJS event integration. By tracking common DOM interactions outside of global change cycles and handling updates through Signals, you keep your application highly performant and secure.

Here is a complete modern implementation of an IdleService tailored for Angular 22.

1. The Idle Service (idle.service.ts)

This service maps user activity to an active timer. If inactivity hits the timeout, it flips an isIdle state and triggers a countdown using signal states that your template can instantly track.

TypeScript
import { Injectable, inject, signal, effect, OnDestroy } from '@angular/core';
import { Router } from '@angular/router';
import { Subject, fromEvent, merge, Subscription } from 'rxjs';
import { switchMap, throttleTime } from 'rxjs/operators';

@Injectable({
providedIn: 'root',
})
export class IdleService implements OnDestroy {
private router = inject(Router);
// Configuration Constants private readonly IDLE_TIMEOUT_MS = 15 * 60 * 1000; // 15 minutes private readonly COUNTDOWN_SECONDS = 60; // 1 minute warning
// Signal States for UI Consumption readonly isIdle = signal<boolean>(false); readonly countdown = signal<number>(this.COUNTDOWN_SECONDS);
private destroy$ = new Subject<void>(); private activitySub?: Subscription; private countdownInterval?: any;
constructor() { this.startTracking();
// Side effect: Automatically handle logout when countdown reaches 0 effect(() => { if (this.isIdle() && this.countdown() <= 0) { this.logoutUser(); } }); }
/** * Initializes user activity listeners. * Leverages throttled RxJS event tracking for high performance. */ startTracking(): void { this.stopTracking(); this.isIdle.set(false); this.countdown.set(this.COUNTDOWN_SECONDS);
const activityEvents$ = merge( fromEvent(window, 'mousemove'), fromEvent(window, 'keydown'), fromEvent(window, 'click'), fromEvent(window, 'scroll'), fromEvent(window, 'touchstart') ).pipe( // Throttling prevents rapid-fire events from over-allocating timers throttleTime(500) );
this.activitySub = activityEvents$ .pipe( // Resets and maps into a delayed execution switchMap(() => new Promise((resolve) => setTimeout(resolve, this.IDLE_TIMEOUT_MS))) ) .subscribe(() => { this.becomeIdle(); }); }
/** * Switches the state to idle and initializes the warning countdown */ private becomeIdle(): void { this.isIdle.set(true); this.stopTracking(); // Stop listening to interactions while warning is active
this.countdownInterval = setInterval(() => { this.countdown.update((current) => current - 1); }, 1000); }
/** * Resets the idle state back to normal if the user signals they are present */ resetIdle(): void { if (this.countdownInterval) { clearInterval(this.countdownInterval); } this.startTracking(); }
private stopTracking(): void { if (this.activitySub) { this.activitySub.unsubscribe(); } if (this.countdownInterval) { clearInterval(this.countdownInterval); } }
private logoutUser(): void { this.cleanup(); this.router.navigate(['/login']); console.warn('User session terminated due to inactivity.'); }
private cleanup(): void { this.stopTracking(); this.destroy$.next(); this.destroy$.complete(); }
ngOnDestroy(): void { this.cleanup(); }
}

2. The Warning Dialog Component (idle-warning.component.ts)

Taking advantage of modern Angular syntax and implicit OnPush default behavior, this component conditionally displays a warning modal instantly reacting to the service's signals.


TypeScript
import { Component, inject } from '@angular/core';
import { IdleService } from './idle.service';

@Component({
selector: 'app-idle-warning', standalone: true, imports: [], template: ` @if (idleService.isIdle()) { <div class="modal-overlay"> <div class="modal-box"> <h2>Are you still there?</h2> <p>Your session will expire shortly due to inactivity.</p> <div class="countdown-timer"> Logging out in: <strong> { { idleService.countdown() }} </strong> seconds </div> <button (click)="stayConnected()">I am still here</button> </div> </div> } `, styles: ` .modal-overlay { position: fixed; top: 0; left: 0; width: 100vw; height: 100vh; background: rgba(0, 0, 0, 0.6); display: flex; justify-content: center; align-items: center; z-index: 9999; } .modal-box { background: var(--bg-color, white); padding: 2rem; border-radius: 12px; text-align: center; box-shadow: 0 10px 25px rgba(0,0,0,0.2); } .countdown-timer { font-size: 1.25rem; margin: 1.5rem 0; color: #d9534f; } button { padding: 0.6rem 2rem; background: #0056b3; color: white; border: none; border-radius: 6px; cursor: pointer; font-weight: 600; } `
})
export class IdleWarningComponent {
protected idleService = inject(IdleService);
stayConnected() { this.idleService.resetIdle(); } }

3. Global Application Wiring (app.component.ts)

Because IdleService is registered at the root, embedding the warning component directly into your root application canvas ensures comprehensive, application-wide user activity monitoring.

TypeScript
import { Component } from '@angular/core';
import { RouterOutlet } from '@angular/router';
import { IdleWarningComponent } from './idle-warning.component';

@Component({
selector: 'app-root', standalone: true, imports: [RouterOutlet, IdleWarningComponent], template: ` <router-outlet /> <app-idle-warning /> `
})
export class AppComponent {}

Highlights of this Modern Implementation

  • Optimized for Zoneless: Older implementations required explicitly forcing event streams into ngZone.runOutsideAngular to protect the browser from frame-drops. Because Angular 22 runs natively zoneless, standard event listeners are incredibly lightweight, and change detection updates are isolated to just the parts of the DOM reading the isIdle and countdown signals.
  • Signal-Driven Declarative Logic: Instead of manually subscribing to multi-layered interval streams in components, the clean @if (idleService.isIdle()) modern control flow automatically binds the template directly to the state primitive.
  • Throttled Interactions: Using throttleTime(500) guarantees that sweeping gestures across the page or aggressive keystrokes don't continually spawn and clear unnecessary timer resources.
