Overview

The purpose of this site is to provide quick access to notes. Most of these notes were generated by Google's Gemini in Chrome. When using AI, you must understand how to properly prompt the AI. You will get better over time as you learn how to properly use it.

Process

I focus on a topic and ask specific questions with enough information for the AI to respond in a way that makes sense. What I mean by this is that if I get a different result when asking the same question multiple times in new sessions, then I know that my prompt is not well defined. This tells me that I need to refine the prompt so there is no ambiguity.

When I get the same response that is 90% the same as previous responses, then I know that my prompt is good. I look at the minor changes between sessions and look for improvements in the response.

Format

In each section, I include the prompt used to generate the response.
